# Changelog

## 3.3.0

- Added conversational trade intents, missing-field checks, contract lookup, and frozen IBKR what-if previews.
- Added human confirmation cards, paper-account checks, broker-warning review, cancellation requests, and order reconciliation.
- Preserved Pi 1.6.0 native capabilities and separate resource, file, Shell, and broker permissions.
- Added public repository documentation, setup examples, and CI.

## 3.2.0

- Added a native Pi CLI entry point with extension, MCP, RPC, and terminal support.
- Made native resource discovery, compaction, retry, and settings configurable.

## 3.1.0

- Integrated the official read, bash, edit, and write tools through independent grants and workspace isolation.

## 3.0.0

- Introduced the standalone Pi application and retained ledger and legacy migration compatibility.
